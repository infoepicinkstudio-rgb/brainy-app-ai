Phase 7 security check: cross-origin request test

This page is deliberately NOT part of the Brainy app itself — opening it this way (double-clicked from a folder, or via file://) makes your browser treat it as a completely different site, so it can test whether Brainy's server correctly refuses requests from somewhere other than itself.

Checking…

Before trusting a PASS here: open http://127.0.0.1:4000/health in another tab first. If that shows text starting with {"status":"ok"...}, the server is definitely running, and the result below is meaningful. If that tab fails to load too, the server just isn't running right now — start it with npm run dev and reload this page.
